## RML Mappings for Enriching Place Name Data

`RMLMappings_PNO_submit.ttl` contains the mapping rules used to enrich place name data using the Place Name Ontology (PNO) as the primary ontology.

`RMLMappings_GNModel_submit.ttl` contains the mapping rules used to enrich place name data using the Geographical Names Model as the primary ontology.
