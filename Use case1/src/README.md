### Note :

Each folder under [src](src) contains the CKAN metadata statement files, the corresponding YARRRML mapping rules, the intermediary RML file (_out.rml.ttl_) and the generated output (_out.ttl_) in Turtle (TTL) format. 
The input JSON files used in this project were downloaded from the [CKAN example datasets](https://github.com/ckan/ckanext-dcat/tree/master/examples/ckan) in the ckanext-dcat GitHub repository.
